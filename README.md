# MR Steel — mrsteel

Tek sayfalık, 4 dilli (TR / EN / RU / KA) çelik konstrüksiyon sitesi. Saf HTML/CSS/JS — kurulum gerekmez.

## Yapı
- `index.html` — tüm site (metinler `I18N` nesnesinde)
- `assets/` — logo ve favicon

## Referans projesi eklemek
1. Fotoğrafı `assets/projects/` klasörüne koyun (ör. `depo-batum.jpg`).
2. `index.html` içindeki `REFERENCES` listesinde ilgili satıra `img:"assets/projects/depo-batum.jpg"` yazın, proje adını 4 dilde düzenleyin.

## Yayın
GitHub → Settings → Pages → Branch: `main` / root. Site `https://blldrmz.github.io/mrsteel/` adresinde açılır.
Dil linkleri: `?lang=tr`, `?lang=en`, `?lang=ru`, `?lang=ka`.
